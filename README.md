# 🎃 Análise e Visualização de Dados de Abóboras (US Pumpkins)

Este projeto realiza o tratamento, exploração e visualização gráfica de dados sobre o mercado de abóboras nos Estados Unidos, utilizando a base de dados `US-pumpkins.csv`.

## 📌 Sobre o Projeto

O objetivo do projeto é importar um conjunto de dados brutos, realizar a filtragem e normalização das variáveis (como padronização de unidades de embalagem e cálculo do preço médio) e gerar visualizações gráficas para interpretar a sazonalidade e distribuição das vendas.

Entre as visualizações geradas, destaca-se o **gráfico de pizza**, criado para ilustrar a proporção das vendas de abóboras ao longo dos meses do ano.

---

## 🚀 Tecnologias Utilizadas

- **Python 3**
- **Pandas**: Manipulação e tratamento dos dados.
- **Matplotlib**: Geração dos gráficos de pizza, dispersão e barras.
- **Seaborn**: Visualização estatística dos dados.

---

## 📊 Gráficos Gerados

1. **Preço Médio por Mês (Gráfico de Barras)**: Análise do comportamento dos preços ao longo do tempo.
2. **Distribuição de Registros por Mês (Gráfico de Pizza)**: Proporção percentual do volume de vendas nos meses de outono/inverno.
